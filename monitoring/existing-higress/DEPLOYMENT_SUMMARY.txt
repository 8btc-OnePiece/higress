📈 关键内存查询（PromQL）
================================================================================

Higress All-in-One 使用 Istio Agent 指标：

1. 已分配内存
-------------------------------------------
istio_agent_go_memstats_alloc_bytes{namespace="agent"}

2. Heap 内存使用
-------------------------------------------
istio_agent_go_memstats_heap_inuse_bytes{namespace="agent"}

3. 内存分配速率
-------------------------------------------
rate(istio_agent_go_memstats_alloc_bytes_total{namespace="agent"}[5m])

4. Goroutines 数量
-------------------------------------------
istio_agent_go_goroutines{namespace="agent"}

5. GC 统计
-------------------------------------------
rate(istio_agent_go_gc_duration_seconds_sum{namespace="agent"}[5m])

6. Stack 内存
-------------------------------------------
istio_agent_go_memstats_stack_inuse_bytes{namespace="agent"}

⚠️  告警规则
================================================================================

级别  | 告警名称                           | 触发条件
------|-----------------------------------|------------------------
WARNING  | HigressGatewayHighMemoryUsage    | 内存使用率 > 80%
CRITICAL | HigressGatewayMemoryNearLimit   | 内存使用率 > 90%
CRITICAL | HigressGatewayPotentialOOM      | 预计1小时内OOM
WARNING  | HigressGatewayMemoryGrowing     | 持续增长2小时
WARNING  | HigressMemorySpike              | 15分钟内增长>20%
WARNING  | HigressHighGoHeapUsage          | Go Heap > 80%
WARNING  | HigressHighGCFrequency          | GC 频率 > 10次/秒

注意：告警规则已自动适配 all-in-one 环境（命名空间: agent）

📝 关键差异说明
================================================================================

Higress All-in-One vs 标准部署：

1. 指标来源
   - All-in-One: istio_agent_* 指标（Istio Pilot Agent）
   - 标准部署: container_memory_* 指标（cAdvisor）

2. Metrics 端口
   - All-in-One: 15020 (pilot-agent)
   - 标准部署: 15020/15021 (Envoy)

3. Pod 名称
   - All-in-One: higress-allinone-*
   - 标准部署: higress-gateway-*, higress-controller-*

4. 命名空间
   - 您的环境: agent
   - 标准部署: higress-system
