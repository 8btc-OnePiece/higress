🚀 部署步骤（3种方式）
================================================================================

方式 1: 一键部署（推荐）⭐
-------------------------------------------
cd /Users/xiaodian/IdeaProjects/higress/monitoring
./setup-higress-monitoring.sh

方式 2: 手动部署
-------------------------------------------
# 1. 安装 Prometheus Operator
./install-prometheus-operator.sh

# 2. 应用 PodMonitor
kubectl apply -f higress-gateway-podmonitor.yaml
kubectl apply -f higress-controller-podmonitor.yaml

# 3. 更新 Higress
cd /Users/xiaodian/IdeaProjects/higress/helm/core
helm upgrade higress . \
  --namespace higress-system \
  --values ../monitoring/higress-values-with-metrics.yaml

# 4. 应用告警规则
kubectl apply -f ../monitoring/higress-memory-alerts.yaml

方式 3: 仅配置 Higress（如果已有 Prometheus）
-------------------------------------------
kubectl apply -f higress-gateway-podmonitor.yaml
kubectl apply -f higress-controller-podmonitor.yaml

📈 关键内存查询（PromQL）
================================================================================

1. Gateway 内存使用量
-------------------------------------------
container_memory_working_set_bytes{
  namespace="higress-system",
  pod=~"higress-gateway.*"
}

2. 内存使用率
-------------------------------------------
rate(container_memory_working_set_bytes{
  namespace="higress-system",
  pod=~"higress-gateway.*"
}[5m]) / container_spec_memory_limit_bytes{
  namespace="higress-system",
  pod=~"higress-gateway.*"
} * 100

3. Go Heap 内存
-------------------------------------------
go_memstats_heap_inuse_bytes{
  namespace="higress-system",
  pod=~"higress-gateway.*"
}

4. 内存使用趋势
-------------------------------------------
rate(container_memory_working_set_bytes{
  namespace="higress-system",
  pod=~"higress-gateway.*"
}[5m])

================================================================================
⚠️  告警规则
================================================================================

级别  | 告警名称                           | 触发条件
------|-----------------------------------|------------------------
WARNING  | HigressGatewayHighMemoryUsage    | 内存使用率 > 80%
CRITICAL | HigressGatewayMemoryNearLimit   | 内存使用率 > 90%
CRITICAL | HigressGatewayPotentialOOM      | 预计1小时内OOM
WARNING  | HigressGatewayMemoryGrowing     | 持续增长2小时
WARNING  | HigressMemorySpike              | 15分钟内增长>20%
WARNING  | HigressHighGoHeapUsage          | Go Heap > 80%
WARNING  | HigressHighGCFrequency          | GC 频率 > 10次/秒

✅ 验证步骤
================================================================================

1. 检查 PodMonitor
-------------------------------------------
kubectl get podmonitor -n higress-system

# 预期输出:
# NAME                    AGE
# higress-gateway         5m
# higress-controller      5m

2. 检查 Prometheus Rule
-------------------------------------------
kubectl get prometheusrule -n higress-system

# 预期输出:
# NAME                        AGE
# higress-memory-alerts       5m

3. 检查 Prometheus Targets
-------------------------------------------
# 访问 Prometheus UI
open http://localhost:9090/targets

# 应该看到:
# - higress-gateway (UP)
# - higress-controller (UP)

4. 查询指标验证
-------------------------------------------
# 在 Prometheus UI 执行:
up{namespace="higress-system"}

# 应该返回值为 1

🔧 故障排查

问题 1: PodMonitor 无数据
-------------------------------------------

kubectl get pod -n higress-system --show-labels

# 检查 PodMonitor selector
kubectl describe podmonitor higress-gateway -n higress-system

# 确认标签匹配

问题 2: Prometheus 无法抓取
-------------------------------------------
# 检查 Pod 端口
kubectl exec -n higress-system \
  $(kubectl get pod -n higress-system -l app=higress-gateway -o jsonpath='{.items[0].metadata.name}') \
  -- netstat -tlnp | grep 15020

# 应该看到 15020 端口监听
